# Дополнительные страницы Sub2API

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文（台灣）](README.zh-TW.md) | Русский

В этом репозитории находятся независимые страницы, которые можно развернуть отдельно и встроить в Sub2API.

## Приложения

| Приложение | Каталог | Описание |
| --- | --- | --- |
| Витрина моделей | [`apps/model-square`](apps/model-square/) | Показывает модели, поставщиков, размер контекста и цены |
| Просмотр документации | [`apps/document-viewer`](apps/document-viewer/) | Показывает несколько документов Markdown в заданном порядке |

Каждое приложение представляет собой отдельный проект со своим исходным кодом, зависимостями, переменными окружения, Dockerfile, файлом Compose и документацией. Приложения не используют общие контейнеры, порты, тома или API.

## Образы контейнеров

GitHub Actions публикует образы в GitHub Container Registry. По умолчанию файлы Compose используют следующие образы с тегом `latest`:

- `ghcr.io/yuzukumo/sub2api-extra-pages-model-square:latest`
- `ghcr.io/yuzukumo/sub2api-extra-pages-document-viewer:latest`

В каждом приложении также есть файл `docker-compose.local.yml` для локальной сборки.

## Порты по умолчанию

Все контейнеры используют внутренний порт `3000`. Порты хоста назначаются последовательно и по умолчанию привязываются только к `127.0.0.1`.

| Приложение | Порт хоста | Порт контейнера |
| --- | --- | --- |
| Витрина моделей | `6001` | `3000` |
| Просмотр документации | `6002` | `3000` |
