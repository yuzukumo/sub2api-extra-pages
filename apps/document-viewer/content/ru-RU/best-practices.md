# Рекомендации

## Выбор модели

Выбирайте модель с учётом задачи, длины контекста, скорости ответа и стоимости. Перед сменой модели в рабочей среде проведите тестирование совместимости.

## Надёжность запросов

- Настройте подходящие тайм-ауты подключения и ответа.
- Повторяйте только те запросы, которые безопасно выполнять повторно.
- При ограничении частоты запросов увеличивайте задержку между повторными попытками по экспоненте.
- Сохраняйте идентификаторы запросов для диагностики.

## Защита учётных данных

> Никогда не храните полные токены доступа в браузерном коде, общедоступных журналах или репозиториях исходного кода.

Загружайте токены доступа на сервере из переменных окружения или системы управления секретами и регулярно обновляйте их с учётом области применения.
