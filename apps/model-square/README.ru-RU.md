# Витрина моделей Sub2API

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文（台灣）](README.zh-TW.md) | Русский

Страница «Витрина моделей» предназначена для встраивания в Sub2API и работает только в режиме просмотра. Интерфейс построен на React, TypeScript и Ant Design. Значки моделей предоставляются пакетом `@lobehub/icons`, а сведения о моделях загружаются из [models.dev](https://models.dev/).

В сервисе нет страницы настройки, административного API или API для записи. Список моделей считывается из `MODEL_IDS` только при запуске процесса.

## Настройка

| Переменная | Обязательна | Значение по умолчанию | Описание |
| --- | --- | --- | --- |
| `MODEL_IDS` | Да | Пример указан в Compose | Идентификаторы моделей через запятую или с новой строки; модели отображаются в алфавитном порядке |
| `NOTICE_MESSAGE` | Нет | Пример указан в Compose | Одно уведомление в верхней части страницы; пустое значение скрывает его |
| `CACHE_FILE` | Нет | `./data/catalog-cache.json` | Файл кэша сведений о моделях |

Пример:

```env
MODEL_IDS=gpt-5.6-sol,gpt-5.6-terra,gpt-5.6-luna
NOTICE_MESSAGE=Model availability and pricing are subject to change.
```

Сервис синхронизируется с models.dev сразу после запуска, а затем ежедневно в 00:00 по местному времени. В примере Compose переменная `TZ` имеет значение `Asia/Singapore`; другой часовой пояс можно указать в этой переменной. Открытие страницы в браузере не запускает синхронизацию. Неизвестные идентификаторы остаются в списке и отображаются с обычным значком и сообщением об отсутствии данных.

## Локальная разработка

```bash
cp .env.example .env
npm install
npm run dev
```

Страница доступна по адресу `http://localhost:4173/`. Vite направляет запросы каталога к локальному API.

Полная проверка проекта:

```bash
npm run check
```

## Развёртывание в Docker

Измените идентификаторы моделей и уведомление в [`docker-compose.yml`](docker-compose.yml). Чтобы использовать образ, опубликованный через GitHub Actions, выполните:

```bash
docker compose pull
docker compose up -d
```

Чтобы собрать образ из исходного кода, выполните:

```bash
docker compose -f docker-compose.local.yml up -d --build
```

В примере Compose адрес `127.0.0.1:6001` сопоставлен с портом `3000` внутри контейнера. При необходимости измените адрес или порты в `docker-compose.yml`.

После изменения переменных окружения Compose выполните `docker compose up -d`. Не ограничивайтесь командой `docker compose restart`: она сохраняет старые переменные окружения существующего контейнера.

## Встраивание в Sub2API

Адрес iframe открывается браузером пользователя и должен быть доступен из этого браузера. Имена сервисов Docker, например `http://sub2apiextra-modelsquare:3000`, обычно распознаются только контейнерами в одной сети Docker.

Для внутренней сети можно использовать внутренний IP-адрес или имя хоста, доступное пользователям. Если Sub2API опубликован в интернете, разместите страницу за тем же обратным прокси-сервером как HTTPS-путь или поддомен. Если Sub2API использует HTTPS, iframe также должен использовать HTTPS, иначе браузер заблокирует смешанное содержимое.

По умолчанию страница следует системной теме. Выбранные вручную тема и язык сохраняются в браузере. Интерфейс доступен на английском, русском, упрощённом китайском и традиционном китайском (Тайвань). Если предпочитаемый язык браузера не поддерживается, используется английский.
